ADVANCE ACADEMY — FREE PUBLIC HOSTING WITH GITHUB PAGES

This is a static website package. It can be hosted publicly so it can open on other phones using a normal web link. It does not require Netlify.

PUBLISH IT (one-time setup; use the same account later to update it):
1. Sign in or create a free account at https://github.com/
2. Open https://github.com/new
3. Repository name: advance-academy
4. Choose Public. Create repository.
5. On the repository page choose Add file > Upload files.
6. Upload index.html from this folder, then click Commit changes.
7. Open the repository Settings > Pages.
8. Under Build and deployment, choose Deploy from a branch.
9. Select branch main and folder /(root), then Save.
10. Wait a few minutes. The public link will be:
   https://YOUR-GITHUB-USERNAME.github.io/advance-academy/
   Replace YOUR-GITHUB-USERNAME with your exact GitHub username.
11. Open that link on any phone. Send the public link through WhatsApp to share it.

IF IT DOES NOT OPEN:
- Go back to Settings > Pages and check the published URL/status.
- Make sure index.html is at the top level of the repository, not inside another folder.
- Wait a few minutes and refresh.

IMPORTANT:
- This ZIP does not publish the website automatically. You must complete the GitHub steps above because only you can sign in to your account and publish it.
- The site is a static practice prototype; question templates are built in and do not fetch brand-new questions from the internet.
- Daily set switching uses the phone's local time; set the phone to India time for 6:00 AM IST.
